Проверка разметки транспорта

Оцените готовые рамки по трём вопросам. Не исправляйте разметку самостоятельно.

  • Полнота: у каждого подходящего объекта есть рамка?
  • Лишние рамки: нет выделений фона, неподходящих объектов и дубликатов?
  • Границы: все нарисованные рамки соответствуют правилам выделения?

Правильная разметка получает три ответа «Да». Пустой список рамок на картинке без транспорта тоже получает три «Да». Если рамок нет, но транспорт есть, полнота — «Нет», остальные два ответа — «Да». При неразборчивой картинке пропустите задание.

Перед ответом увеличьте изображение, проверьте мелкие объекты и при необходимости скройте рамки. Правила выделения приведены ниже.
